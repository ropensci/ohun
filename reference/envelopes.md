# Class 'envelopes': list of absolute amplitude envelopes

Class for absolute amplitude envelopes

## Details

An object of class `envelopes` created by
[`get_envelopes`](https://docs.ropensci.org/ohun/reference/get_envelopes.md)
is a list with sound files absolute amplitude envelopes and metadata
